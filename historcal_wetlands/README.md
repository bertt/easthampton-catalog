# Historcal Wetlands

Mirror of the "Historcal Wetlands" layer (layer 50, in the service's "Town Wetlands" group) of the Town of East Hampton's [MapServiceForOpenGov](https://eh-gis.ehamptonny.gov/arcgis/rest/services/MapServiceForOpenGov/MapServer) ArcGIS service. 40 polygon features, kept in the source CRS EPSG:2263. The service warns that it contains draft data that may be incomplete. The publisher describes it as: "This layer shows wetland boundaries that were digitized from historic surveys which were georeferenced in the GIS. The layer is incomplete and draft." Credit given by the publisher on this layer: TOEH IT Department GIS, TOEH Planning Department, Lisa D'Andrea. See [AGENTS.md](AGENTS.md) for the schema, quirks and query recipes.
